# dialogic-extensions
A repository for useful extension modules for the dialogic plugin.


To use an extension, 
1) Add the folder to your 'dialogic extensions folder' as defined in your General Settings.
<img width="1172" height="426" alt="image" src="https://github.com/user-attachments/assets/aae51888-c449-4b86-acac-d456f08de7fa" />
2) Reload your project 

Extensions can be subsystems, custom layers, custom events and more. 

While we try to only provide quality extensions in this repository, Dialogic extensions are provided as is and are maintained by their creators. Report any issues to this repository, but be aware fixes may not be prompt.
